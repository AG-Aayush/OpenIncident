# OpenIncident

OpenIncident is an open-source, AI-powered incident response agent. It investigates production incidents, correlates evidence from things like logs, metrics, and deployment history, and helps determine what's actually wrong and what to do about it — with a human able to step in for anything risky.

The goal is for the AI to be part of the decision-making loop itself, not just a chatbot that summarizes logs.

## Status
🚧 Early ideation / design phase. Architecture, tech stack, and scope are still being worked out and will likely change.
